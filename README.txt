Портфолио: как пользоваться
1. Откройте index.html в браузере.
2. Имя и email: в конце index.html, блок CONFIG.
3. Кнопка «Скачать CV»: положите файл cv.pdf рядом с index.html.
4. Тексты (RU/EN) и описания работ: там же, в блоках T и GROUPS.
5. Чтобы выложить в интернет: загрузите всю папку на Netlify, Vercel или GitHub Pages.
